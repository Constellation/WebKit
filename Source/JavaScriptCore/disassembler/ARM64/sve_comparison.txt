Summary of Issues:
------------------
1. SVE unpredicated arithmetic: Missing element size suffixes (.b, .h, .s, .d)
2. SVE predicated operations: Wrong register types and missing /m modifier
3. SVE load/store: Missing destination register in braces
4. FAMAX SIMD: Wrong operand extraction (getting wrong registers and sizes)
5. FAMAX SVE: Using 'd0' instead of 'z0.h'

This indicates the SVE/SME operand formatting logic needs enhancement in the generator.
